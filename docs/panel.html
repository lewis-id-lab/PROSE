Why haplotype terms

The unfinished predecessor analysis simulated three PTX3 SNPs as independent multiplicative risks. They are in near-complete linkage disequilibrium and tag one h1/h2 haplotype, so independent simulation triple-counts a single signal. The same error would recur within CLEC7A and CD209 if their two SNPs each entered as additive terms. The panel therefore enters as four haplotype terms, with IL10 and IFNG as optional single SNPs. TLR9 rs352140 is dropped (one usable study of three).

Haplotype phase check

Haplotype frequencies were derived from allele frequencies and D, assuming the minor alleles are in coupling (D positive). D′ near 1 fixes the size of D but not its sign. The reported r² and the allele frequencies fix |D| independently of that assumption, so the sign can be checked arithmetically: if even the largest possible negative D is smaller than the |D| that r² requires, negative phase is impossible.

Code 
phase <- hap |>
  group_by(gene, locus_1, locus_2) |>
  summarise(
    r2 = first(r2),
    p1 = sum(haplotype_freq_1000G_EUR[!allele_1 %in% c("major", "other")]),
    p2 = sum(haplotype_freq_1000G_EUR[!allele_2 %in% c("major", "other")]),
    .groups = "drop"
  ) |>
  mutate(
    required_D = sqrt(r2 * p1 * (1 - p1) * p2 * (1 - p2)),
    ceiling_if_negative = pmin(p1 * p2, (1 - p1) * (1 - p2)),
    negative_possible = required_D <= ceiling_if_negative + 1e-3
  )

phase |>
  transmute(Gene = gene, `Locus 1` = locus_1, `Locus 2` = locus_2,
            `Required |D|` = required_D, `Ceiling if D < 0` = ceiling_if_negative,
            `Negative phase possible` = ifelse(negative_possible, "yes", "no")) |>
  gt() |>
  fmt_number(c(`Required |D|`, `Ceiling if D < 0`), decimals = 4)

All six pairs are consistent only with coupling. The check assumes r² and D′ were taken from the 1000 Genomes source and not back-calculated from the assumed D.

  summarise(

    p1 = sum(haplotype_freq_1000G_EUR[!allele_1 %in% c("major", "other")]),
