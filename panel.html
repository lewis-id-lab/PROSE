Why haplotype terms

The unfinished predecessor analysis simulated three PTX3 SNPs as independent multiplicative risks. They are in near-complete linkage disequilibrium and tag one h1/h2 haplotype, so independent simulation triple-counts a single signal. The same error would recur within CLEC7A and CD209 if their two SNPs each entered as additive terms. The panel therefore enters as four haplotype terms, with IL10 and IFNG as optional single SNPs. TLR9 rs352140 is dropped (one usable study of three).

            `Independent cohorts` = n_independent_cohorts, `Study IDs` = study_ids) |>

Herrero-Sanchez 2018 is excluded from the primary analysis because its endpoint is Candida or Aspergillus detection or colonisation and not proven or probable invasive mould disease. The cohort counts above include it, and excluding it takes PTX3 from 7 to 6 and CLEC7A from 9 to 8.

Linkage disequilibrium

Pairwise values in 1000 Genomes European samples.

Code 
hap |>
  distinct(gene, locus_1, locus_2, r2, d_prime) |>
  transmute(Gene = gene, `Locus 1` = locus_1, `Locus 2` = locus_2, `r²` = r2, `D′` = d_prime) |>
  gt() |>
  fmt_number(c(`r²`, `D′`), decimals = 3)

For CLEC7A, D′ = 1 means no recombination between the two sites. The rare Y238X allele (rs16910526) therefore sits entirely on one rs7309123 background, and the low r² reflects the frequency difference and not independence. For CD209, D′ = 0.67 and all four haplotypes are present.

Haplotype phase check

Haplotype frequencies were derived from allele frequencies and D, assuming the minor alleles are in coupling (D positive). D′ near 1 fixes the size of D but not its sign. The reported r² and the allele frequencies fix |D| independently of that assumption, so the sign can be checked arithmetically: if even the largest possible negative D is smaller than the |D| that r² requires, negative phase is impossible.

Code 
phase <- hap |>
  group_by(gene, locus_1, locus_2) |>
  summarise(
    r2 = first(r2),
    p1 = sum(haplotype_freq_1000G_EUR[!allele_1 %in% c("major", "other")]),
    p2 = sum(haplotype_freq_1000G_EUR[!allele_2 %in% c("major", "other")]),
    .groups = "drop"
  ) |>
  mutate(
    required_D = sqrt(r2 * p1 * (1 - p1) * p2 * (1 - p2)),
    ceiling_if_negative = pmin(p1 * p2, (1 - p1) * (1 - p2)),
    negative_possible = required_D <= ceiling_if_negative + 1e-3
  )

phase |>
  transmute(Gene = gene, `Locus 1` = locus_1, `Locus 2` = locus_2,
            `Required |D|` = required_D, `Ceiling if D < 0` = ceiling_if_negative,
            `Negative phase possible` = ifelse(negative_possible, "yes", "no")) |>
  gt() |>
  fmt_number(c(`Required |D|`, `Ceiling if D < 0`), decimals = 4)

All six pairs are consistent only with coupling. The check assumes r² and D′ were taken from the 1000 Genomes source and not back-calculated from the assumed D. The phased chromosomes below confirm it directly.

Phased haplotype frequencies

These come directly from phased 1000 Genomes phase 3 European genotypes (503 samples, 1,006 chromosomes, via the Ensembl REST API), then are rescaled to the gnomAD v4 non-Finnish-European allele frequencies that the project uses as primary. Rescaling is by iterative proportional fitting, which keeps the odds-ratio structure of the observed table, moves only the allele frequencies, and works for three loci. A haplotype that is absent in 1000G stays absent.

PTX3, three loci

Alleles are in the order rs2305619, rs3816527, rs1840680.

Code 
hp |>
  filter(block == "PTX3_trio", n_chromosomes > 0) |>
  arrange(desc(freq_1000G_EUR)) |>
  transmute(Haplotype = haplotype, Chromosomes = n_chromosomes,
            `1000G EUR` = freq_1000G_EUR, SE = se_1000G_EUR, `gnomAD NFE (rescaled)` = freq_gnomAD_NFE_rescaled) |>
  gt() |>
  fmt_number(c(`1000G EUR`, SE, `gnomAD NFE (rescaled)`), decimals = 4)

There are three common haplotypes, not two. rs2305619 A and rs1840680 A mark the same class of chromosome (r² = 0.996), which is A-C-A plus A-A-A. rs3816527 C splits that class, and A-C-A is about 87% of it. The single A-A-G chromosome is too rare to estimate; its rescaled frequency is fixed by the margins alone.
