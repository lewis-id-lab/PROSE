What “exact” means here

Net benefit at threshold \(t\) is the true-positive rate minus the false-positive rate weighted by \(t/(1-t)\). The baseline model has seven binary predictors, so there are only 128 predictor profiles, each with a known risk. Given the probability of each profile, net benefit at every threshold is an exact calculation: sort the profiles by risk, flag those at or above \(t\), and add up. No patient-level sample is drawn.

The profile probabilities come from numerical integration of the fitted 7-dimensional normal, not from simulating patients. The integrator (mvtnorm) uses a randomised quasi-Monte Carlo rule internally, with the error target set to \(10^{-7}\) per profile. Repeat runs with different seeds agree to about \(10^{-6}\), which is below any difference that matters here, and the test suite checks this.

The same code takes separate “decision” and “outcome” risks, so once genetic terms enter the data-generating model it can score a clinical-only rule against the true risk without change.

ImportantThe curve and bands below come from the fitted copula

Since decisions D9 and D10 (18 October 2026), the baseline cohort for the genetic layer is the observed distribution of the clinical profiles in the 4,078 unique admissions of boscore.xlsx (the 49 non-event twin rows removed), with patients resampled in the bootstrap, and the baseline model is a refit on that cohort. The curve and bands below are the copula’s with the published equation, a sensitivity analysis. The MCID table at the end of this page shows the adopted refit values next to the earlier ones.

The minimum clinically important difference

The pre-specified MCID (reading b) is 20% more true cases of invasive mould disease at no increase in false positives, which in net-benefit terms is 0.2 times the baseline true-positive rate at the threshold. The 5% threshold is primary, because it is the cut-off the Stanzani paper used to define high risk. The 20% threshold is secondary.

ref <- read.csv("data/baseline_net_benefit_reference.csv")
q_v1 <- read.csv("output/v1/profile_probabilities.csv")
risk <- plogis(profile_logit(pars, all_profiles()))

base <- read.csv("output/dca_baseline_summary.csv")
refit <- read.csv("output/dca_baseline_refit_summary.csv")
sel <- function(d, col) d[[col]][d$threshold %in% c(0.05, 0.20)]
tibble(
  Threshold = c("5% (primary)", "20% (secondary)"),
  `Indicative (rho = 0.30)` = ref$mcid_b_20pc_more_tp[ref$threshold %in% c(0.05, 0.20)],
  `Copula v1` = v1$mcid_b,
  `Copula v2 (at the lock)` = sel(summ, "mcid_b"),
  `v2 ensemble 5%` = sel(summ, "mcid_lo"),
  `v2 ensemble 95%` = sel(summ, "mcid_hi"),
  `4,127 rows (D8)` = sel(emp, "mcid_b"),
  `Published equation, base cohort (D9)` = sel(base, "mcid_b"),
  `Refit baseline (adopted)` = sel(refit, "mcid_b"),
  `Refit bootstrap 5%` = sel(refit, "mcid_lo"),
  `Refit bootstrap 95%` = sel(refit, "mcid_hi"),
  `Observed outcomes` = sel(base, "observed_mcid")
) |>
  gt() |>
  fmt_number(where(is.numeric), decimals = 5)
Code 
i5 <- which(abs(fit$threshold - 0.05) < 1e-9)
ok <- abs(fit$mcid_b / fit$mcid_b[i5] - 1) < 0.05
lo <- i5; while (lo > 1 && ok[lo - 1]) lo <- lo - 1
hi <- i5; while (hi < length(ok) && ok[hi + 1]) hi <- hi + 1
plateau <- fit$threshold[c(lo, hi)]

The primary value is stable across the four cohorts (within about 6% of the indicative figure), while the secondary value falls by about a quarter. The adopted refit-baseline values are +0.00458 at 5% and +0.00160 at 20%. They are higher than the published-equation values (+0.00404 and +0.00113) because the published equation under-predicts slightly on the corrected cohort (3.06% predicted against 3.26% observed), so adopting the refit makes the primary test harder for the genetic layer. Results are also reported against the published-equation and 4,127-row values. The 5% value sits on a plateau: the MCID stays within 5% of its value at 5% for thresholds from about 4.2% to 7.8%. The spread across the ensemble, about plus or minus 7% at 5% and plus or minus 18% at 20%, is the part that rests on the unpublished correlation structure.

How much does the MCID depend on the outcome risk?

The published equation was fitted with the 49 twin rows in, and on the corrected cohort it under-predicts slightly (3.06% predicted against 3.26% observed). So the MCID can be computed under different readings of the “true” outcome risk. The decision rule is the published equation’s, except in scenario C. Patients are resampled, with the refit repeated inside every resample.

Code 
sens <- read.csv("output/mcid_outcome_risk_sensitivity.csv")
sens |>
  transmute(Scenario = scenario, Threshold = threshold, MCID = mcid_b, `5%` = mcid_lo, `95%` = mcid_hi,
            `Relative to A` = mcid_relative_to_A, `True positives per 1,000` = tp_per_1000) |>
  gt(groupname_col = "Threshold") |>
  fmt_percent(`Relative to A`, decimals = 0) |>
  fmt_number(c(MCID, `5%`, `95%`), decimals = 5) |>
  fmt_number(`True positives per 1,000`, decimals = 1)

The adopted value (A, published equation as truth) is the lowest at every threshold. The alternatives raise the primary MCID by 9 to 13% and the secondary by 21 to 41%, which makes the adopted reading the most permissive one for the primary test. The intervals overlap, so the data cannot separate the readings, and the published coefficient lies inside the refit’s interval for every term:

The 4,127-row MCID (+0.00445 at 5%, +0.00142 at 20%) sits close to the refit-truth and observed-outcome readings, so reporting against it, as decision D9 commits to, brackets them.

Using the machinery for the genetic layer

# Cells: clinical profile x genetic class. Decisions use the clinical-only risk;
# outcomes use the true risk including genetics.
base  <- dca_exact(w, risk_true, risk_pred = risk_clinical)
with  <- dca_exact(w, risk_true, risk_pred = risk_with_genetics)
dca_compare(base, with)   # delta_nb, the baseline MCID, and whether it is met

dca_compare() takes the MCID from the baseline curve, so the test is fixed by the baseline and cannot drift with the candidate model.

Limitations

  • Results are for the baseline alone. No genetic term has been added.
  • The ensemble spread reflects only the correlation structure. It does not include uncertainty from admission clustering or from using the apparent aROC of 0.85.
  • Net benefit is per admission. Patients with several admissions contribute correlated events, which matters for uncertainty but not for the exact point values here.
